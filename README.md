# gta6-assets

Тайлы и картинки для интерактивной карты [Grand Theft Auto VI](https://broskiplay.ru/gta6-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/leonida-mg/<z>/<x>/<y>.webp` (256×256, z8–z16, сетка MapGenie, WebP q90) и `manifest.json` — список существующих тайлов
- `tiles/leonida/` — прежняя подложка (z0–z8), удалить после публикации карты на новых тайлах
- `popups/<id>.webp` — картинки к меткам (WebP q90, не больше 1920×1080)
